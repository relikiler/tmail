## 1. Project Name

**TMAIL — E2E-Encrypted Web3 Email** («почтовое отделение, которое не вскрывает конверты»)

## 2. One-line pitch

Децентрализованная почта с end-to-end шифрованием, где сервер — «слепой курьер»: он технически не может прочитать ни одно письмо.

## 3. Category

General Grant / Direct Grant → Web3 Infrastructure / Privacy / Public Goods

## 4. Problem → Solution

**Проблема.** Традиционная электронная почта (Gmail, Яндекс и др.) — это ценрализованная инфраструктура: сервер видит всю переписку, может читать, блокировать и монетизировать данные без ведома пользователя. Приватность отсутствует по умолчанию.

**Решение.** TMAIL шифрует письма end-to-end прямо в браузере (X25519 + AES-256-GCM). Сервер хранит только метаданные (`from/to/ts/size`) и **никогда не видит темы, тела или ключи** — это архитектурная невозможность, а не «политика доверия».

**Бэкенд:** Node.js / Fastify, SQLite (WAL), IPFS-вложения (Pinata). Бэкапы, fail2ban, Caddy.

**Клиент:** React + Vite (web), Tauri v2 + Rust (desktop/Android), 6 языков.

**Крипто:** X25519 + AES-256-GCM, ed25519-подписи, Argon2id (пароль), recovery-ключ.

**Вход:** MetaMask, WalletConnect, вход по паролю (для сетей с блокировками).

**Открытый код:** https://github.com/relikiler/tmail

## 6. Why Polygon?

- Полный стек уже работает на **Polygon PoS** — контракты задеплоены и в деле.
- Модель freemium (Free 7 писем/день → Premium/Pro) **генерирует постоянный поток транзакций** и сжигает газ/токены — создаёт устойчивую активность в сети.
- Самоокупаемость: подписки + Lifetime Pass = постоянный доход, а не разовый грант.
