Roadmap

Our journey towards fully decentralized communication.

Phase 1: Web Client

Launch of the core web application with wallet login, basic E2EE, and TMAIL integration on Polygon.

Phase 2: IPFS Attachments

Decentralized file storage integration. Send encrypted files stored on IPFS directly through your emails.

Phase 3: Desktop App (Tauri)

Native desktop applications for Windows, macOS, and Linux built with Tauri for maximum performance and security.

Phase 4: Blockchain Mode

Fully on-chain messaging protocol for censorship-resistant communication.
